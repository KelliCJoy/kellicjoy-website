# Kelli C Joy — Fine Art Studio

A standalone painting portfolio prepared for GitHub Pages. Open `index.html` to preview. No Shopify account, installation, or build step is required.

## Included

- Bright ivory, pale blue, and understated blush styling inspired by your Shopify Studio settings.
- An About the Artist section with Kelli’s portrait, Storyscape biography, and tribute to Joy Deckard.
- Your original logo and one painting, “A Hearts Dream,” with two detail views.
- An accessible enlarged-image viewer with keyboard navigation.
- Email inquiries directed to info@kellicjoy.com.
- Mobile layout and reduced-motion support.

The photographs are rotated and cropped for presentation; the full-painting photograph is corrected for camera perspective. These web images use embedded DNG previews. Keep your original DNG files for archival and high-resolution use. No colors were intentionally changed. Confirm the crop and color appearance before publishing.

## Publish with GitHub Pages

1. Create a repository in your GitHub account. GitHub Free supports Pages from public repositories, so the website files will be visible publicly.
2. Upload the contents of this folder to the repository root, including the assets folder.
3. In Settings → Pages, select “Deploy from a branch,” choose the main branch and `/ (root)`, then save.
4. Review the generated github.io website before connecting kellicjoy.com.
5. Verify kellicjoy.com in your account’s Pages settings. Add the verification TXT record at your domain provider.
6. Add kellicjoy.com in the repository’s Pages custom-domain setting, then configure its web DNS records using GitHub’s guide below.
7. Enable HTTPS when GitHub makes it available, and check both kellicjoy.com and www.kellicjoy.com.

Preserve the existing email DNS records (MX and relevant TXT records) so info@kellicjoy.com continues to receive mail. Keep domain registration active. Change only the website records when connecting the new host.

Do not cancel the existing website plan until the replacement works and any remaining content is backed up. No hosting, domain, or email settings have been changed by preparing this folder.

GitHub guide: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
